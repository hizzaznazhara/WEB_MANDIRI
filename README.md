# GrowSimulator

GrowSimulator adalah proyek frontend bertema Growtopia. Proyek ini menyediakan simulator latihan Surgery, panduan strategi Villains, dan halaman Kritik & Saran.

## Fitur

- **Dashboard**: pintasan ke simulator Surgery dan Villains Guide.
- **Surgery Simulator**: latihan kasus Surgery dengan tool yang ditampilkan sesuai langkah dan kondisi pasien.
- **Villains Guide**: daftar Villains, Masterminds, Supervillains, kartu yang disarankan, dan strategi.
- **Kritik & Saran**: form frontend untuk mengirim masukan atau koreksi panduan. Form ini belum terhubung ke backend dan tidak menyimpan data.

## Teknologi

- HTML, CSS, dan JavaScript
- Bootstrap 5

### Alasan memilih Bootstrap

Bootstrap dipilih karena menyediakan sistem grid dan komponen siap pakai untuk menyusun dashboard, tabel, navigasi, dan form secara konsisten. Class responsif seperti row-cols, col, dan utility spacing juga membantu halaman menyesuaikan diri dengan layar mobile maupun desktop.

## Cara menjalankan

Proyek ini berupa halaman statis. Buka `index.html` di browser, lalu gunakan navigasi untuk membuka halaman lain. Koneksi internet diperlukan untuk memuat Bootstrap dari CDN.

## Halaman

| File | Isi |
| --- | --- |
| `index.html` | Dashboard GrowSimulator |
| `surgery.html` | Simulator latihan Surgery |
| `crime.html` | Panduan Villains Growtopia |
| `form.html` | Form Kritik & Saran |
